# Поворот квадрата в консоли

Программа на C рисует в консоли контур квадрата, повёрнутого на заданный угол. Для отображения границы используется введённый символ.

## Что делает программа

1. Запрашивает символ для рисования, длину стороны и угол поворота в градусах.
2. Переводит угол в радианы.
3. Перебирает точки условной сетки. Координаты `x` масштабируются вдвое, чтобы квадрат выглядел более пропорционально в текстовом окне.
4. Поворачивает координаты каждой точки и проверяет, попадает ли точка на одну из четырёх сторон квадрата. Если попадает — печатает выбранный символ, иначе пробел.
5. После вывода рисунка спрашивает, нужно ли повторить ввод и построить новый квадрат.


## Ввод

- **Символ** — знак, которым будет нарисован контур.
- **Сторона** — положительное целое число; оно задаёт размер фигуры в условных координатах.
- **Угол** — угол поворота в градусах.
- **Продолжить?** — введите `0`, чтобы завершить программу, или любое другое целое число, чтобы построить следующую фигуру.

## Алгоритм проверки точки

Для точки `(x, y)` вычисляются координаты после обратного поворота:

```text
a = (x / 2) · cos(угол) + y · sin(угол)
b = -(x / 2) · sin(угол) + y · cos(угол)
```

Точка печатается как часть контура, если она находится вблизи одной из вертикальных или горизонтальных сторон квадрата со стороной `storona`. Допуск `0.6` учитывает дискретность консольной сетки.
